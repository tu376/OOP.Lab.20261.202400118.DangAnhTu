1. What happens if users choose "Cancel"?
- Cancel bug: The original code only checks option == JOptionPane.YES_OPTION, so both "No" and "Cancel" fall into the same else branch and get displayed as "No". The fix checks YES_OPTION and NO_OPTION separately, then treats anything else (Cancel or closing the dialog) as its own case.

2. How to customize the options to users, e.g. only two options: “Yes” and “No”, OR “I do” and “I don’t”
- showConfirmDialog() can only use Java's built-in button sets, so it can't show custom text like "I do" / "I don't". showOptionDialog() solves this by accepting an Object[] array of your own button labels and returning the index of whichever one was clicked.
