1. What happens if users choose "Cancel"?
- JOptionPane.showConfirmDialog(...) returns an int. When the dialog type includes a Cancel button (YES_NO_CANCEL_OPTION), clicking it returns the constant JOptionPane.CANCEL_OPTION (value 2). Closing the dialog with the window's X button instead returns JOptionPane.CLOSED_OPTION (value -1) — these are two different outcomes, so your code should check for both if you want to treat "Cancel" and "closed without choosing" separately. Nothing happens automatically; it's up to your code (e.g. the switch above) to decide what to do — commonly, abort the current operation and return without further action.

2. How to customize the options to users, e.g. only two options: “Yes” and “No”, OR “I do” and “I don’t”
- showConfirmDialog only offers Java's built-in button sets (Yes/No, Yes/No/Cancel, OK/Cancel) with fixed English labels — it can't relabel buttons. To customize the text, use JOptionPane.showOptionDialog(...) instead, and pass your own Object[] array of button labels (e.g. {"I do", "I don't"}). It returns the index into that array (0, 1, ...) instead of a named constant, or JOptionPane.CLOSED_OPTION if the dialog is closed unanswered.
